# ROBO-platform 3.0

## Запуск
Распакуйте архив целиком, сохранив структуру папок. Откройте `index.html` двойным щелчком в современном браузере. Сервер, npm, сборка, Python и интернет не требуются.

## Структура
- `index.html` — интерфейс и нативные ES-модули маршрутизации и приложения. Модуль карты импортируется через Blob URL для локального запуска.
- `css/styles.css` — стили, острые углы, светлая и тёмная темы, адаптивность.
- `assets/map.png` — схема Frame 2 (681×309); стартовая отметка приведена к базовому голубому цвету, текущую станцию окрашивает интерактивный слой.
- `assets/locations/location0.png` … `location9.png` — десять оригинальных изображений мебели без изменения размера и пересжатия. Их координаты заданы отдельными SVG-изображениями в `index.html` в соответствии с Frame 3. Верхний объект обрезан границей комнаты так же, как на визуальном образце.
- `audio/README.txt` — инструкция для необязательных локальных записей.

## Карта и управление
На старте робот находится на станции 08. При отправлении прежняя станция становится голубой, а при прибытии новая — розовой на карте и в списке. При выборе станции окно с отправкой и временем появляется рядом с ней. Во время движения виден розовый квадрат робота. Сохраняются положение, заряд, скорость, тема и громкость (`localStorage`, ключ `robo-platform.v3`); маршрут версии 3 восстанавливается по времени. При наличии доступного состояния версии 2 сохраняется номер последней известной станции; старый незавершённый маршрут не переносится на новую геометрию, начальная точка в этом случае — 08. Браузер может ограничить локальное хранилище при `file://`; тогда приложение показывает предупреждение.

Масштаб условный (0,025 м/px), маршруты строятся по сетке A* с шагом 4 px и отступом 5 px от приблизительных контуров препятствий. Вес не редактируется в интерфейсе, заряд расходуется при движении. Это визуальная симуляция, а не система безопасного управления физическим роботом.

## Аудио
Нажатие PoPiPo, Spider-Man, Star Wars или Bad Apple!! запускает цикл длительностью 10 секунд. Статус — «Поет», активная кнопка голубая, индикатор заполняется от 0:00 до 0:10. Повторное нажатие на активную кнопку ничего не делает (паузы нет); другая кнопка начинает новый цикл. По завершении отображается фактический статус навигации: «В ожидании груза» или «Доставляет». При выключении, ошибке или столкновении цикл прерывается. Воспроизведение не сохраняется после перезагрузки.

Аудиозаписи не предоставлены, поэтому по умолчанию цикл без звука. Если добавить свои файлы в `audio/` с указанными в инструкции именами, они будут воспроизводиться автоматически при нажатии, без диалогов выбора файла, в пределах 10-секундного цикла. Громкость регулируется ползунком.

## Проверка
Проверены синтаксис ES-модулей, все 64 пары станций, сохранение текущей станции, 10-секундный аудиоцикл, переключение мелодий, отключение питания и сочетание аудио с движением. Логика интерфейса проверена в JavaScript с имитацией DOM; полноценная браузерная проверка в тестовой среде ограничена.
